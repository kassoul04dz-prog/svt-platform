منصة علوم الطبيعة والحياة — النسخة المصحّحة لأخطاء 502 (الدوال بالصيغة الحديثة)
الأستاذة قسول إيمان

ما الذي كان يسبّب 502 (حسب وثائق Netlify)
  1) انتهاء مهلة الدالة: الدوال العادية لها 10 ثوانٍ، وتجاوزها يظهر للمستخدم 502.
     استدعاء نموذج الذكاء الاصطناعي لمسودات الأستاذ الطويلة قد يتجاوزها.
  2) الدوال القديمة (exports.handler) لا يُهيَّأ لها تخزين Blobs تلقائياً (خطأ MissingBlobsEnvironmentError)
     فتنهار لوحة التحكم عند أول قراءة أو كتابة.
  3) كنتُ أُرجع 502 بنفسي عندما يرفض مزوّد الذكاء الاصطناعي الطلب (مفتاح خاطئ، اسم نموذج خطأ، رصيد منتهٍ).
  4) توليد 200 كود وقراءة مئات الأكواد بالتتابع قد يتجاوز 10 ثوانٍ.
  5) غياب تثبيت الحزم (@netlify/blobs) عند النشر بسطر الأوامر دون npm install.

ما تغيّر
  - كل الدوال بالصيغة الحديثة (export default + Request/Response): Blobs يعمل تلقائياً.
  - التحقق من الحساب يتم بسؤال Identity نفسها عن الرمز (لا يعتمد على clientContext القديم).
  - كل دالة ملفوفة بـ wrap(): أي عطل يرجع JSON فيه السبب (HTTP 500) بدل 502 غامض، ويُسجَّل في Function logs.
  - البوت: ردود التلميذ بمهلة داخلية 8 ثوانٍ (إن تأخر المزوّد يرجع ai_timeout وتظهر تلميحات ثابتة).
  - مهام الأستاذ الطويلة تُنفَّذ في دالة خلفية bot-background (حتى 15 دقيقة) ويستعلم عنها المتصفح تلقائياً.
  - أخطاء المزوّد تُرجَع واضحة: ai_key_invalid، ai_model_not_found، ai_bad_request (رصيد)، ai_busy...
  - توليد الأكواد حتى 100 في الطلب وبتزامن محدود، وقراءة الأكواد بتزامن محدود.
  - الملفات: تُحوَّل القطعة إلى ArrayBuffer قبل التخزين (Blobs لا يقبل Buffer مباشرة).
  - دالة جديدة health لتشخيص الإعدادات.
  - إصلاح خلل في الواجهة: فشل تحميل لوحة التحكم كان يمسح نموذجها فلا تعود دون تحديث الصفحة.

الملفات (انسخي المجلد كاملاً فوق القديم؛ الأسماء نفسها فتُستبدل)

  netlify/functions/bot.js        بوت التلميذ + استعلام المهام
  netlify/functions/bot-background.js   مساعد الأستاذ (خلفي)   [جديد]
  netlify/functions/health.js     فحص الصحة                    [جديد]

  netlify/lib/common.js، ai.js [جديد]، platform.js

النشر
  1) استبدلي المحتوى في مستودع GitHub بهذا المجلد (محتوياته في جذر المستودع، لا داخل مجلد فرعي) ثم Commit.
     (إن نشرتِ بسطر الأوامر: نفّذي أولاً npm install ثم netlify deploy --prod.)
  2) Project configuration ← Environment variables:
       ADMIN_EMAILS        بريدك (إجباري)
       ANTHROPIC_API_KEY   مفتاح Anthropic (للبوت؛ اختياري)
       AI_MODEL, AI_MODEL_TEACHER   اختياري
  3) Identity مفعّل، ثم Trigger deploy.

التشخيص (الأهم)
  افتحي:  https://موقعك.netlify.app/.netlify/functions/health
  وللتحقق من مفتاح الذكاء الاصطناعي واسم النموذج:  ...health?ai=1
  يعرض: هل Blobs يعمل، هل Identity مفعّل، هل المتغيرات مضبوطة، وهل النموذجان صالحان.
  وإن بقي خطأ: Netlify ← Logs ← Functions ← اختاري الدالة وانسخي آخر سطر خطأ لي.

حدود
  - لم أجرّب الحزمة على Netlify نفسها؛ اختبرتها محلياً بتخزين وهمي وهوية تجريبية (74 فحصاً ناجحاً).
  - مهلة الدالة العادية 10 ثوانٍ في Netlify؛ لا تتجاوزيها بإعداد في netlify.toml.
  - إن لم تُقبل دوال الخلفية في خطتك فستفشل مسودات الأستاذ الطويلة وحدها، وباقي المنصة تعمل (أخبريني).
